## Top stories {#top}

- {:#n261111-01} **Microsoft November Patch Tuesday: 1,094 flaws, one exploited Outlook zero-day** `#vuln` `ZERO-DAY` `EXPLOITED` `PATCH` — CVE-2026-124194 is an Outlook spoofing flaw (CVSS 6.5) that lets a malicious message file leak the user's NTLMv2 hash; it needs the file to be opened (the preview pane does not trigger it) and affects Microsoft 365 Apps and Office LTSC 2021/2024. Windows accounts for 726 of the fixes. *Why it matters:* leaked NTLMv2 hashes can be relayed or cracked, so patch Office and restrict outbound NTLM/SMB. [SecurityWeek](https://www.securityweek.com/exploited-outlook-zero-day-among-1094-flaws-patched-by-microsoft/)
- {:#n261111-02} **Chrome 157 fixes exploited XML use-after-free (CVE-2026-125350)** `#vuln` `HIGH` `ZERO-DAY` `EXPLOITED` `PATCH` — Eighth Chrome zero-day exploited this year; fixed in 157.0.8103.50/.51 (Windows/Mac) and .50 (Linux), reported by an anonymous researcher on 6 November. Not yet in CISA KEV at time of writing. *Why it matters:* browsers remain the most reliable initial-access target; restart Chrome and other Chromium browsers. [SecurityWeek](https://www.securityweek.com/chrome-update-patches-exploited-xml-zero-day-eighth-this-year/)
- {:#n261111-03} **Qubole supply-chain attack: a dozen-plus organizations breached through AWS cross-account roles** `#breach` `#supply-chain` — An attacker used compromised IAM credentials of Qubole's AWS account to assume roles customers had created, many left behind after they stopped using the platform, then harvested secrets and exfiltrated whole S3 buckets (14–26 October). *Why it matters:* it is a clean example of stale third-party trust relationships; audit and remove unused cross-account roles. [SecurityWeek](https://www.securityweek.com/over-a-dozen-organizations-hit-in-qubole-supply-chain-attack/)
- {:#n261111-04} **SAP patches critical ICM2SHELL and ProxyGate flaws** `#vuln` `CRITICAL` `PATCH` — ICM2SHELL (CVE-2026-76964 / CVE-2026-89126) is unauthenticated RCE via WebSocket message reassembly in the ICM / Web Dispatcher; ProxyGate (CVE-2026-89103) lets attackers spoof internal requests on SAP Gateway to run OS commands. *Why it matters:* the Onapsis data from this week's briefs says SAP exploitation follows patches in 1-3 days. [SecurityWeek](https://www.securityweek.com/sap-patches-critical-icm2shell-proxygate-vulnerabilities/)

### SN #1103 — "Exposing Bad Consumer Crypto"

- {:#n261111-09} **EDK II PXE boot flaw (CVE-2026-97631)** `#vuln` `CRITICAL` — A 16-year-old buffer overflow (rated 9.5) in the PXE Base Code driver's ICMP handling in TianoCore EDK II lets an attacker on the local network run code before the OS, Secure Boot and TPM measurements kick in during network boot. Steve: serious, but not a home-user risk; mostly a "forever bug" for servers on unsupported firmware. Mitigate by disabling PXE where unused. [SC Media](https://www.scworld.com/brief/critical-firmware-vulnerability-discovered-in-tianocore-edk-ii) · [oss-security](https://openwall.com/lists/oss-security/2026/10/28/4) · [Transcript](https://www.grc.com/sn/sn-1103.txt)

Steve counted it as another third-party-script lesson. [BleepingComputer](https://bleepingcomputer.com/news/security/polymarket-halts-trading-after-crypto-draining-script-breach-25m-traced) · [Transcript](https://www.grc.com/sn/sn-1103.txt)
