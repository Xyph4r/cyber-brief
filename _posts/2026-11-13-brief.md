## Top stories {#top}

- **Windows "SignDrop" CLFS zero-day gives SYSTEM, no patch yet** `#vuln` `ZERO-DAY` `POC` — Researcher Abdelhamid Naceri published a proof-of-concept for a flaw in how the Common Log File System driver creates its `.cnpf` authentication file; abused when a privileged process such as Windows Defender opens the log, it yields SYSTEM and can be used to disable AV/EDR tamper protection. Tested on Windows 11 26H2 and Server 2025; no in-the-wild exploitation reported yet. *Why it matters:* a public local-privilege-escalation exploit with no fix is ideal post-compromise tooling for ransomware crews. [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-windows-signdrop-zero-day-gives-hackers-system-privileges/)
- **N-able "4EverAble2Shell" zero-day exploited hours after PoC** `#vuln` `ZERO-DAY` `EXPLOITED` `UPDATE` — Chains an Apache Axis flaw (CVE-2026-90436) with an N-central privilege escalation for root command execution, requiring the Legacy API to be enabled. Exploitation began 12 November; at least 21 servers are compromised, mostly running Monero miners, 19 of them on the 10 November Hotfix 2 build. N-able disabled the Intune integration and urges on-prem customers to confirm the Legacy API is off. *Why it matters:* the hotfixes covered yesterday did not close this; RMM platforms remain a prime MSP supply-chain target. [BleepingComputer](https://www.bleepingcomputer.com/news/security/new-n-able-4everable2shell-zero-day-exploited-hours-after-poc-released/) · [SecurityWeek](https://www.securityweek.com/hackers-target-n-central-zero-days-as-n-able-rushes-patches/)
- **"wfx-loot": 4,800 hijacked GitHub accounts probe 61,000 repos for secrets** `#threat` `#supply-chain` — Stolen credentials from 4,837 accounts were used to find repositories with write access, then push disguised pull requests and credential-stealing scripts via GitHub Actions workflows, short-lived branches or npm install hooks. Secret theft is confirmed at 1,835+ targets, including AWS, Azure and Google Cloud credentials. *Why it matters:* CI/CD secrets are a direct route into cloud accounts; look for a `wfx-docs` branch and gaps in workflow run numbers, and rotate secrets. [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-compromise-4-800-github-accounts-to-steal-cloud-credentials/) · [SecurityWeek](https://www.securityweek.com/attacker-targets-60000-github-repositories-in-credential-theft-campaign/)
- **Operation Endgame hits Gootloader, CastleRAT and StealC** `#industry` `#threat` — Europol/Eurojust-coordinated police from nine countries seized 257 domains and 235 servers and identified 6.4 million victim credential datasets, being shared with Have I Been Pwned. *Why it matters:* infostealer and loader takedowns cut off the initial-access supply for ransomware; check HIBP for your accounts. [BleepingComputer](https://www.bleepingcomputer.com/news/security/police-dismantles-gootloader-castlerat-stealc-malware-infrastructure/)
