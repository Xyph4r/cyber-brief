## Top stories {#top}

- {:#n261105-01} **OpenSSH 10.6p2: oversized password bypasses auth on musl-based Linux** `#vuln` `CRITICAL` `PATCH` — A bug (nicknamed "*sshole") lets attackers with network access log into password-disabled or key-only accounts on some setups such as Alpine Linux by submitting a very long password; heise notes it probably does not originate in OpenSSH itself. *Why it matters:* it undermines the standard "disable passwords, use keys" hardening advice on affected systems. [The Hacker News](https://thehackernews.com/2026/11/openssh-issues-emergency-fix-for-flaw.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/openssh-flaw-lets-attackers-log-into-password-disabled-linux-accounts/) · [heise](https://www.heise.de/news/OpenSSH-und-Alpine-Linux-warnt-vor-nischigem-aber-gravierendem-Bug-11513105.html)
- {:#n261105-02} **OpenAI AI pipeline generates 948 Linux root-escalation exploits** `#threat` `#ai` — An unreleased OpenAI cyber model found and validated 948 kernel local-privilege-escalation bugs in a ~30-hour run costing roughly $1.2M in API usage. *Why it matters:* exploit development is becoming cheap and automatable at scale. [SecurityWeek](https://www.securityweek.com/ai-agents-got-root-on-linux-via-948-kernel-flaws-in-openai-research/) · [The Hacker News](https://thehackernews.com/2026/11/openai-ai-pipeline-generates-948-linux.html)
- {:#n261105-03} **Zyxel GS1900 attacks actually used a zero-day (CVE-2026-107441)** `#vuln` `HIGH` `ZERO-DAY` `EXPLOITED` `UPDATE` — Attacks first blamed on a patched bug exploited an out-of-bounds write giving OS command execution via crafted HTTP requests; nearly 1,000 switches were compromised and the earlier patch doesn't block it. Newer firmware does. *Why it matters:* "patched" doesn't mean safe here. [SecurityWeek](https://www.securityweek.com/zyxel-switch-hacks-blamed-on-patched-flaw-actually-exploited-a-zero-day/) · [The Hacker News](https://thehackernews.com/2026/11/zyxel-gs1900-patch-fails-to-block-zero.html) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/zyxel-fixes-zero-day-exploited-to-hack-nearly-1-000-network-switches/)
