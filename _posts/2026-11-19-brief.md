## Top stories {#top}

- {:#n261119-01} **"nginx2root": 10-year-old NGINX HTTP/2 flaw allows unauthenticated code execution** `#vuln` `CRITICAL` `POC` `PATCH` — CVE-2026-123007 (CVSS 4.0: 9.2) affects open-source NGINX 1.9.5 through 1.31.8 and is fixed in 1.31.9 and 1.30.7 (NGINX Plus 37.3.0.1 / 37.0.8.1; no fix listed for R34–R36). Wiz, Xint and Rapid7 analysed it and public PoC code is on GitHub; no exploitation reported yet. *Why it matters:* NGINX fronts a huge share of the web, and public PoC code usually means scanning follows quickly. [The Hacker News](https://thehackernews.com/2026/11/10-year-old-nginx-http2-flaw-lets.html)
- {:#n261119-02} **Apache Roller unauthenticated RCE is being exploited** `#vuln` `CRITICAL` `EXPLOITED` `PATCH` — CVE-2026-129448 (CVSS 9.8) is a deserialization bug in the XML-RPC endpoint of Roller 4.0.0–6.1.4; fixed in 6.1.6 or later. The ASF says it is actively exploited but has shared no details. *Why it matters:* a pre-auth deserialization RCE on an internet-facing blog platform is trivial to automate. [The Hacker News](https://thehackernews.com/2026/11/critical-apache-roller-rce-flaw-under.html)
- {:#n261119-03} **PHP security release today fixes critical flaws in all supported versions** `#vuln` `CRITICAL` — Maintainers pre-announced a release for 19 November (about 14:00 UTC) including CVE-2026-115560, an RCE that needs `session.serialize_handler` switched to `php` via `ini_set()` before `session_start()` with session upload progress on (the default). Interim mitigation: `session.upload_progress.enabled=0` and restart workers. *Why it matters:* patch quickly once it lands; PHP is everywhere. [The Hacker News](https://thehackernews.com/2026/11/php-warns-of-critical-security-flaws.html)
- {:#n261119-04} **Microsoft's `agent-framework` PyPI package poisoned with a credential stealer** `#breach` `#supply-chain` `#ai` — Versions 1.26.1 and 1.26.2 (published 17 November, 33 minutes apart) drop a `.pth` file that runs on every Python start and steals env vars, cloud and Azure tokens, sending them to a webhook. Pin to 1.26.0, rotate secrets from a clean host, check proxy/DNS logs and audit CI. *Why it matters:* a `.pth` startup hook runs without any import, so installing is enough. [The Hacker News](https://thehackernews.com/2026/11/attackers-compromise-microsofts-agent.html) · [SecurityWeek](https://www.securityweek.com/microsoft-agent-framework-releases-poisoned-with-credential-stealer/)
