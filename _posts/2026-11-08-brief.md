## Top stories {#top}

- {:#n261108-01} **German intelligence services investigate European supermarket refrigeration sabotage** `#threat` `#ot` `#germany` `UPDATE` — Verfassungsschutz and BND are reportedly investigating the attacks on supermarket cooling systems, which have since spread to French blood-storage facilities and prompted an FBI/CISA warning. *Why it matters:* the case is being treated as sabotage rather than ordinary cybercrime. [heise](https://www.heise.de/news/Supermarkt-Kuehlsysteme-Deutsche-Geheimdienste-ermitteln-nach-Sabotageakten-11516390.html) · [SecurityWeek](https://www.securityweek.com/us-agencies-urge-organizations-to-harden-refrigeration-controllers/)
- {:#n261108-02} **Claude Code "Don't Ask Again" file leaks secrets in 1,122 public GitHub copies** `#vuln` `#ai` — Secrets typed into commands that the user approved with "don't ask again" are saved in a project settings file, which many developers then committed to public repositories. *Why it matters:* AI coding-agent config files are the new `.env` leak; check and gitignore them. [The Hacker News](https://thehackernews.com/2026/11/claude-codes-dont-ask-again-file.html)
- {:#n261108-03} **Synology: ransomware exploits a December 2024 DSM flaw on outdated NAS** `#vuln` `#ransomware` `HIGH` `EXPLOITED` `PATCH` — Attackers are encrypting NAS devices that run old DSM versions; the fix is in advisory Synology-SA-24:20. Update DSM and enable automatic updates. *Why it matters:* a second NAS-targeting campaign this week (after QNAP Plex2Shell), this time using a nearly two-year-old bug. [Synology advisory](https://www.synology.com/zh-tw/security/advisory/Synology_SA_24_20) · [SecurityWeek](https://www.securityweek.com/in-other-news-trezor-implant-llmjacking-bills-hit-1m-sap-flaws-weaponized-within-days/)
- {:#n261108-04} **Crédit Mutuel Arkéa heist: up to $133M via a service provider** `#breach` `UPDATE` — The bank confirmed a cyberattack that allowed fraudulent transactions of up to $133M and suspended some systems. *Why it matters:* it is the third-party-provider route again. [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-pull-off-133-million-french-bank-heist-via-service-provider/)
