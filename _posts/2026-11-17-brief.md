## Top stories {#top}

- {:#n261117-01} **Google: threat actors now use agentic AI frameworks in live intrusions** `#threat` `#ai` — Google Threat Intelligence Group reports multi-agent offensive frameworks such as ARTEX, CAIRN, CyberStrikeAI and PentAGI automating phases of real intrusions, and LLM-driven patch diffing to weaponize flaws faster (seen with PaperCut NG/MF). *Why it matters:* the gap between patch release and exploitation keeps shrinking, so patch latency matters more. [Google Cloud](https://cloud.google.com/blog/topics/threat-intelligence/agentic-threat-activity-crosses-a-significant-threshold) · [The Hacker News](https://thehackernews.com/2026/11/google-finds-hackers-using-ai-agents-to.html)
- {:#n261117-02} **Barracuda breached in Artex-powered intrusion** `#breach` `#threat` `#ai` `UPDATE` — Chinese actors are widely using the Artex agentic pentest framework (public on GitHub since July); an exposed cloud access key let the attacker reach about 10 Barracuda cloud accounts in roughly 44 hours. Barracuda has not named a group. *Why it matters:* follows the FBI flash alert and shows exposed keys plus AI speed is a potent mix. [SecurityWeek](https://www.securityweek.com/barracuda-hacked-amid-surge-in-artex-powered-cyberattacks/)
- {:#n261117-03} **N-able patches 17 N-central flaws as earlier bugs are exploited** `#vuln` `CRITICAL` `EXPLOITED` `PATCH` — N-central 2026.4 Hotfix 3 fixes CVE-2026-129271 to CVE-2026-129287 (auth bypass, local privilege escalation, XXE, path traversal to RCE). Attackers are exploiting the earlier "4EverAble2Shell" flaws to drop crypto miners; these need legacy API mode, now removed. *Why it matters:* RMM platforms give access to every managed customer. On-prem servers need manual upgrade; agents and probes must be upgraded too. [The Hacker News](https://thehackernews.com/2026/11/n-able-patches-17-n-central-flaws-as.html)
- {:#n261117-04} **Google Project Zero drops its 30-day grace period** `#industry` `#ai` — From 13 November details are published 90 days after report even if unpatched, shrinking to 60 days in February 2027 and 30 days in January 2028 (exceptions for exploited or public flaws). *Why it matters:* AI-assisted bug finding and exploitation is changing coordinated disclosure norms. [SecurityWeek](https://www.securityweek.com/google-project-zero-sets-course-for-30-day-disclosure-deadline/)
