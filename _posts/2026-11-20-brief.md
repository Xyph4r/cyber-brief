## Top stories {#top}

- {:#n261120-01} **VMware vCenter auth bypass exploited as a zero-day by suspected Chinese APT** `#vuln` `CRITICAL` `ZERO-DAY` `EXPLOITED` `PATCH` — CVE-2026-123890 (CVSS 9.8) in the VMware Directory Service gives an unauthenticated attacker an admin session. Mandiant ties it to Armory Castle (formerly UNC5221 / Warp Panda), which got in via a BeyondTrust Remote Support zero-day, stole SAML signing material, forged tokens and moved on to ESXi. Fixed in vCenter 9.1.1.0200, 9.0.2.0200 and 8.0 U3m; vCenter 7.0 is out of support with no public patch. *Why it matters:* vCenter controls the whole virtual estate, and the attackers held SSO and encryption keys, so patching alone does not evict them. [Google/Mandiant](https://cloud.google.com/blog/topics/threat-intelligence/armory-castle-exploits-vsphere) · [Broadcom advisory](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39495) · [SecurityWeek](https://www.securityweek.com/newly-patched-vmware-vcenter-flaw-exploited-as-zero-day-by-chinese-apt/) · [The Hacker News](https://thehackernews.com/2026/11/critical-vmware-vcenter-flaw-cvss-98.html)
- {:#n261120-02} **PHP ships fixes for seven critical flaws** `#vuln` `CRITICAL` `PATCH` `UPDATE` — The release pre-announced yesterday is out: CVE-2026-115560 and CVE-2026-129182 (both CVSS 9.2) are fixed in PHP 8.2.36, 8.3.37, 8.4.28, 8.5.13 and 8.6.0. A separate session-storage flaw, CVE-2026-126714, can become code execution with an app gadget chain. *Why it matters:* it affects every supported branch, so update now. [The Hacker News](https://thehackernews.com/2026/11/php-fixes-7-critical-flaws-including.html) · [SecurityWeek](https://www.securityweek.com/php-patches-seven-critical-rce-vulnerabilities/) · [phpAfterShell explainer](https://thehackernews.com/2026/11/phpaftershell-explained-how-hackers.html)
