## Top stories {#top}

- **ScreenConnect abused to breach MSPs and their customers** `#threat` `#supply-chain` — Huntress reports attackers compromised ScreenConnect environments of six MSPs and used Run Command to push rogue remote-access clients to 286+ endpoints across 47 organizations. No CVE is involved; it abuses legitimate functionality. ConnectWise disabled five third-party extensions across about 400 partner environments, which does not remove existing access. *Why it matters:* MSP tooling gives attackers one-to-many reach, so review Run Command history and logs. [BleepingComputer](https://www.bleepingcomputer.com/news/security/active-screenconnect-attacks-breach-msps-impact-dozens-of-organizations/)
- **Critical Xen Orchestra flaws exploited, one still unpatched** `#vuln` `CRITICAL` `EXPLOITED` `ZERO-DAY` — An authentication bypass (reusable login tokens) gives unauthenticated admin access; fixed in 6.9.2 (stable) / 6.10.1 (latest). A second admin-only flaw via malicious VM imports can compromise XCP-ng hosts and has no fix yet. No CVEs assigned. *Why it matters:* hypervisor management planes are crown-jewel targets and Vates warns access may not be logged. [SecurityWeek](https://www.securityweek.com/critical-xen-orchestra-flaws-exploited-in-attacks/)
- **Maersk confirms breach as WhiteArmor demands $5M** `#breach` `#ransomware` — An intruder accessed and extracted data from a legacy system Maersk inherited via an acquisition; the group claims about 100GB. Maersk says no sensitive data has been disclosed so far. *Why it matters:* acquired legacy systems are a recurring weak point. [BleepingComputer](https://www.bleepingcomputer.com/news/security/maersk-confirms-data-breach-as-whitearmor-ransomware-demands-5-million/)
- **AI pentest tool AntiFox used in AWS credential theft** `#threat` `#ai` — Arctic Wolf saw attackers run self-hosted AntiFox (open-source, forked from ARTEX 0.1.1) on Alibaba Cloud to exploit web services, drop webshells and harvest AWS secrets, making hundreds of API calls in about 30 minutes. *Why it matters:* offensive AI tooling compresses attack timelines; revoke exposed sessions and rotate keys. [BleepingComputer](https://www.bleepingcomputer.com/news/security/hackers-use-antifox-ai-agents-in-aws-credential-theft-attacks/)
