- **OpenSSH 10.6p2: oversized password bypasses auth on musl-based Linux** `#vuln` `CRITICAL` `PATCH` — A bug (nicknamed "*sshole") lets attackers with network access log into password-disabled or key-only accounts on some setups such as Alpine Linux by submitting a very long password; heise notes it probably does not originate in OpenSSH itself. *Why it matters:* it undermines the standard "disable passwords, use keys" hardening advice on affected systems.
