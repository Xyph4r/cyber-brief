- **Microsoft's `agent-framework` PyPI package poisoned with a credential stealer** `#breach` `#supply-chain` `#ai` — Versions 1.26.1 and 1.26.2 (published 17 November, 33 minutes apart) drop a `.pth` file that runs on every Python start and steals env vars, cloud and Azure tokens, sending them to a webhook. Pin to 1.26.0, rotate secrets from a clean host, check proxy/DNS logs and audit CI. *Why it matters:* a `.pth` startup hook runs without any import, so installing is enough.
