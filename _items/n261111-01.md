- **Microsoft November Patch Tuesday: 1,094 flaws, one exploited Outlook zero-day** `#vuln` `ZERO-DAY` `EXPLOITED` `PATCH` — CVE-2026-124194 is an Outlook spoofing flaw (CVSS 6.5) that lets a malicious message file leak the user's NTLMv2 hash; it needs the file to be opened (the preview pane does not trigger it) and affects Microsoft 365 Apps and Office LTSC 2021/2024. Windows accounts for 726 of the fixes. *Why it matters:* leaked NTLMv2 hashes can be relayed or cracked, so patch Office and restrict outbound NTLM/SMB.
