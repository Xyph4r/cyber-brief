- **ScreenConnect abused to breach MSPs and their customers** `#threat` `#supply-chain` — Huntress reports attackers compromised ScreenConnect environments of six MSPs and used Run Command to push rogue remote-access clients to 286+ endpoints across 47 organizations. No CVE is involved; it abuses legitimate functionality. ConnectWise disabled five third-party extensions across about 400 partner environments, which does not remove existing access. *Why it matters:* MSP tooling gives attackers one-to-many reach, so review Run Command history and logs.
