- **EDK II PXE boot flaw (CVE-2026-97631)** `#vuln` `CRITICAL` — A 16-year-old buffer overflow (rated 9.5) in the PXE Base Code driver's ICMP handling in TianoCore EDK II lets an attacker on the local network run code before the OS, Secure Boot and TPM measurements kick in during network boot. Steve: serious, but not a home-user risk; mostly a "forever bug" for servers on unsupported firmware. Mitigate by disabling PXE where unused.
