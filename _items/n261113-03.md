- **"wfx-loot": 4,800 hijacked GitHub accounts probe 61,000 repos for secrets** `#threat` `#supply-chain` — Stolen credentials from 4,837 accounts were used to find repositories with write access, then push disguised pull requests and credential-stealing scripts via GitHub Actions workflows, short-lived branches or npm install hooks. Secret theft is confirmed at 1,835+ targets, including AWS, Azure and Google Cloud credentials. *Why it matters:* CI/CD secrets are a direct route into cloud accounts; look for a `wfx-docs` branch and gaps in workflow run numbers, and rotate secrets.
