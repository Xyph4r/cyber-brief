- **CVE-2026-119618 — Apache HTTP Server mod_http2** `CRITICAL` `PATCH` — Race condition corrupting heap memory, potentially unauthenticated RCE. Affects 2.4.55–2.4.70 and standalone mod_h2 2.0.8–2.0.42, only with HTTP/2 enabled (not default). Found by Anthropic's OSS Scanner and Google Cloud's vulnerability research team; update to the latest release.
