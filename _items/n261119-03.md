- **PHP security release today fixes critical flaws in all supported versions** `#vuln` `CRITICAL` — Maintainers pre-announced a release for 19 November (about 14:00 UTC) including CVE-2026-115560, an RCE that needs `session.serialize_handler` switched to `php` via `ini_set()` before `session_start()` with session upload progress on (the default). Interim mitigation: `session.upload_progress.enabled=0` and restart workers. *Why it matters:* patch quickly once it lands; PHP is everywhere.
