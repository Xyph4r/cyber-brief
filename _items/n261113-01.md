- **Windows "SignDrop" CLFS zero-day gives SYSTEM, no patch yet** `#vuln` `ZERO-DAY` `POC` — Researcher Abdelhamid Naceri published a proof-of-concept for a flaw in how the Common Log File System driver creates its `.cnpf` authentication file; abused when a privileged process such as Windows Defender opens the log, it yields SYSTEM and can be used to disable AV/EDR tamper protection. Tested on Windows 11 26H2 and Server 2025; no in-the-wild exploitation reported yet. *Why it matters:* a public local-privilege-escalation exploit with no fix is ideal post-compromise tooling for ransomware crews.
